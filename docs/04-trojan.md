# 04 木马生成

**入口**：左侧菜单「攻击」→「木马生成」→ `/attack/trojan`

按语言和类型生成 WebShell 代码，支持在线编辑、复制、下载。生成的文件需要你自己通过**文件上传漏洞、任意文件写入、数据库导出、日志包含**等方式落到目标服务器上——本页只负责「造马」，不负责「投递」。

> 💡 **本页模板是明文一句话，过不了任何查杀工具。** 需要免杀/图片马/自定义图标时，用页面上的 **🛡 免杀生成器** 按钮（扩展模块），见 [19 木马免杀生成器](19-trojan-evasion.md)。

> ⚠️ 仅可用于授权靶场/比赛。把木马写到未授权系统属于违法犯罪。

## 1. 页面结构

```
[编程语言]  [木马类型]  [选择模板]
   模板说明 / 文件名
   木马代码（可编辑，15 行高）
   [下载木马] [复制代码]
   使用说明
```

### 1.1 编程语言

| 值 | 适用目标 |
|---|---|
| `PHP` | 绝大多数 AWD Web 题（默认） |
| `JSP` | Tomcat / Java Web |
| `ASPX` | IIS / .NET |

### 1.2 木马类型（4 类）

| 类型 | 特点 | 适用场景 |
|---|---|---|
| 经典一句话 | 最短、最容易被查杀 | 目标无 WAF、对手不查杀 |
| 自定义参数 | 改密码/参数名，避开通用规则 | 有基础查杀 |
| 编码混淆 | Base64/异或/Unicode | 绕关键字检测 |
| 高级变体 | 无特征、回调、反射、动态编译 | 对手有 WebShell 扫描 |

## 2. 内置模板一览

> 下拉菜单会随语言/类型变化，以下为主要模板；实际以页面为准。

### PHP

| 类型 | 模板 | 说明 | 默认文件名 |
|---|---|---|---|
| 经典一句话 | 经典一句话 | `<?php @eval($_POST['pass']);?>` | `shell.php` |
| 经典一句话 | POST 变体 | 变量存密码再 eval | `shell_post.php` |
| 经典一句话 | GET 变体 | `$_GET['pass']` | `shell_get.php` |
| 自定义参数 | 自定义密码 | `$pwd='YOUR_PASSWORD'` | `shell_custom.php` |
| 自定义参数 | 多参数 | `fun` + `cmd` 两个参数 | `shell_multi.php` |
| 编码混淆 | Base64 编码 | `eval(base64_decode(...))` | `shell_base64.php` |
| 编码混淆 | 异或加密 | 运行时异或还原再 eval | `shell_xor.php` |
| 高级变体 | 无特征 | 类 + `__invoke` 混淆，无常规特征串 | `shell_advanced.php` |
| 高级变体 | 回调后门 | `usort($_POST,'assert')` 回调执行 | `shell_callback.php` |

### JSP

| 类型 | 模板 | 说明 |
|---|---|---|
| 经典一句话 | 经典一句话 / 执行命令 | `Runtime.getRuntime().exec(cmd)` |
| 自定义参数 | 自定义参数 | 可改参数名 |
| 编码混淆 | Unicode 编码 | 关键字 Unicode 化 |
| 高级变体 | 反射执行 | 反射调用，规避部分规则 |

### ASPX

| 类型 | 模板 | 说明 |
|---|---|---|
| 经典一句话 | 经典一句话 / 直接执行 | `Process.Start(Request["cmd"])` |
| 自定义参数 | 自定义密码 | 密码校验后执行 |
| 编码混淆 | Base64 编码 | Base64 解码载荷 |
| 高级变体 | 动态编译 | `Assembly.Load(...).CreateInstance(...)` |

## 3. 操作步骤

1. 选「编程语言」（如 PHP）；
2. 选「木马类型」（如 经典一句话）；
3. 在「选择模板」下拉里选具体模板；
4. 页面显示模板说明和默认文件名；
5. 在「木马代码」框中按需修改：
   - 把 `pass` / `YOUR_PASSWORD` 换成你自己的密码；
   - 需要隐蔽时替换变量名、函数名；
6. 点 **下载木马**（按默认文件名保存），或 **复制代码** 粘贴到上传点/写入点；
7. 上传成功后，到「Shell 管理」→ 添加 Shell → 类型 WebShell → 填 URL 和密码 → 测试连接。

## 4. 选型建议

| 场景 | 推荐 |
|---|---|
| 开局快速拿 Shell | 经典一句话，密码改成随机串 |
| 对手会批量查杀 | 高级变体「无特征」/ 回调后门 |
| 有 WAF 拦 `eval`、`assert` | Base64/异或编码，或 JSP 反射 |
| PHP 禁用了 `system` 等函数 | 用 `eval` 类，或改投「不死马/内存马」 |
| 目标为 Java | JSP 执行命令（注意 Tomcat 版本与 JDK 模块限制） |
| 目标为 IIS | ASPX 直接执行（需 .NET 权限足够） |

## 5. 投递思路（配合其他模块）

1. **文件上传漏洞**：改后缀（`.php`、`.phtml`、`.php5`）、改 Content-Type、加图片头、`.htaccess`/`.user.ini`；
2. **任意文件写入**：日志包含、Session 文件包含、缓存文件；
3. **数据库写入**：`SELECT ... INTO OUTFILE`（需 `secure_file_priv` 允许）；
4. **已有 Shell 写入**：用「Shell 管理 → 文件管理」直接上传/新建文件；
5. 投递后**务必验证**：浏览器访问返回空白是正常的，用 `POST pass=phpinfo();` 测试。

## 6. 常见问题

**Q：下载后文件名不对？**
A：下载按钮使用模板默认文件名；需要自定义就在下载后重命名，或复制代码自行保存。

**Q：上传成功但访问 404/403？**
A：后缀被拦截、目录不可执行、或文件被重命名。换后缀/换目录，或先传 `.htaccess` 让 `.jpg` 当 PHP 执行。

**Q：访问返回源码？**
A：目标未解析 PHP（或缺 PHP-FPM），换 JSP/ASPX 或找可执行目录。

**Q：连接成功但执行命令无回显？**
A：`disable_functions` 禁用了命令函数；改用文件管理读 Flag，或换用未被禁用的函数（`pcntl_exec`、`putenv`+`mail` 等）。

**Q：生成的马被目标 WebShell 扫描秒删？**
A：用「高级变体」并改密码/变量名；或先部署 WAF、再投放；也可以改用「权限维持」里的不死马。
